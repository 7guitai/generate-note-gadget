# 記事スタイルガイド

## 文体

- **基本**: です・ます調（丁寧語）
- **口調**: 同世代〜少し年上の先輩が教えてくれる感じ。親しみやすく、押し付けがましくない
- **一人称**: 「私」または「筆者」
- **二人称**: 「あなた」は避け、「読者のみなさん」も避ける。直接呼びかけは最小限に
- **学生向け配慮**: 専門用語には簡単な補足を添える。予算に配慮した表現を心がける

## タイトルの作り方

### ルール
- 28字以内
- 数字・記号（【】）を使って目を引く
- 読者のメリット・ベネフィットを含める
- 「学生向け」「大学生」などターゲットを明示すると検索に強い

### 良い例
- 「【学生向け】1万円以下イヤホン5選｜コスパ重視」
- 「大学生のiPad活用術｜ノートアプリ3つを比較」
- 「一人暮らし大学生の充電器選び｜GaN充電器が最適解」

### 悪い例
- 「ワイヤレスイヤホンについて」（曖昧・メリット不明）
- 「最新ガジェットを紹介します！」（抽象的・ターゲット不明）

## 記事構成

### 単一商品紹介記事（review）
```
1. リード文（200字）：学生の悩みに共感 → この記事で解決できることを提示
2. 商品の基本スペック概要（箇条書き・表）
3. 詳細レビュー（良い点・気になる点を具体的に）
   - スペックの意味を噛み砕いて説明
   - 学生の生活シーンに紐づけて使用感を伝える
4. こんな学生におすすめ / こんな人には向かない
5. 類似製品との簡単比較（表形式）
6. まとめ + アフィリエイトCTA
```

### 比較記事（comparison）
```
1. リード文（200字）：「どれを選べばいいか迷っている人へ」
2. 比較表（スペック・価格・特徴を一目で把握できるもの）
3. 各製品の詳細レビュー
   - 1製品ごとにスペック・長所・短所を丁寧に解説
   - 他の製品との違いを具体的に明示
4. シーン別おすすめ（予算・用途・学部・ライフスタイル別）
5. まとめ：結局どれを買うべきか、明確な結論
6. アフィリエイトCTA
```

## 詳細比較のポイント（差別化の核）

- **数値で比較**: 「音質が良い」ではなく「ドライバーサイズ10mm、対応コーデックはAAC/LDAC」のように具体的に
- **実際の使用シーンで比較**: 「通学の電車内」「図書館での自習」「オンライン講義中」など
- **コスパを計算で示す**: 「1日あたり約〇〇円」「月額〇〇円のサブスクと比べると…」
- **学生目線の判断基準**: 「バイト代1回分で買える」「教科書1冊分の値段」など身近な比較

## 見出し（H2/H3）の書き方

### H2（大見出し）
- 読者がその見出しだけ読んでも内容がわかるレベル
- 例: 「1万円以下で買えるノイキャンイヤホン、本当に使える？」

### H3（小見出し）
- 具体的なポイントを示す
- 例: 「通学中の電車ノイズはどれくらいカットできるか」

## アフィリエイトリンクの入れ方

### 挿入タイミング
1. 商品紹介直後（最初の言及箇所）
2. 「おすすめ度が高い」と評価した直後
3. 記事末尾のまとめ/CTA

### プレースホルダー記法
```
[AFFILIATE: 商品名 | Amazon]
[AFFILIATE: 商品名 | 楽天]
```

### 文脈の作り方（自然な誘導）
- 悪い例: 「こちらから購入できます → リンク」
- 良い例: 「Amazonで最新価格をチェック → [AFFILIATE: ...]」
- 良い例: 「楽天のポイント還元を考えるとこちらもお得 → [AFFILIATE: ...]」

## Note特有の注意事項

- **改行**: Noteはスマホ閲覧が多いので、2〜3行で段落を区切る
- **太字**: 重要ポイントは `**太字**` で強調（多用しない）
- **画像**: `[画像: 説明]` プレースホルダーで場所を示す（実際の画像は手動挿入）
- **ハッシュタグ**: 記事末尾に5〜8個（例: #大学生 #学生おすすめ #コスパ最強）
- **アフィリエイト開示**: 必ず記事の最初か最後に開示文を入れる

## NGワード・表現

- 「最高」「最強」「絶対」など根拠のない最上級表現（単独使用）
- 「〇〇必見！」「衝撃の結果！」などのクリックベイト見出し
- 根拠のない「売れてます」「人気です」
- メーカー・ブランドの誹謗中傷
- 学生の経済状況を軽視する表現（「これくらい安い」「買わない理由がない」など）
