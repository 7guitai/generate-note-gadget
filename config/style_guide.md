# 記事スタイルガイド

## 文体

- **基本**: です・ます調（丁寧語）
- **口調**: 親しみやすく、専門知識がある友人が教えてくれる感じ
- **一人称**: 「私」または「筆者」
- **二人称**: 「あなた」は避け、「読者のみなさん」も避ける。直接呼びかけは最小限に

## タイトルの作り方

### ルール
- 28字以内
- 数字・記号（【】）を使って目を引く
- 読者のメリット・ベネフィットを含める
- 「〇〇とは」より「〇〇で解決」系が効果的

### 良い例
- 「AirPods Pro 2レビュー｜ノイキャン性能を正直評価」
- 「【2025年】ワイヤレスイヤホンおすすめ5選｜コスパ重視」
- 「Anker vs UGREEN充電器比較！3000円で買うべきはどっち？」

### 悪い例
- 「ワイヤレスイヤホンについて」（曖昧・メリット不明）
- 「最新ガジェットを紹介します！」（抽象的）

## 記事構成

### レビュー記事
```
1. リード文（200字）：読者の悩みに共感 → この記事で解決できることを提示
2. 商品スペック概要（箇条書き）
3. 実際に使ってみた感想（良い点・悪い点を正直に）
4. こんな人におすすめ / こんな人には向かない
5. 競合製品との簡単比較
6. まとめ + アフィリエイトCTA
```

### 比較記事
```
1. リード文（200字）：「どっちにするか迷っている人へ」
2. 比較表（スペック・価格・特徴）
3. 各製品の詳細評価
4. シーン別おすすめ（用途・予算・ライフスタイル別）
5. まとめ：結局どっちを買うべきか
6. アフィリエイトCTA
```

## 見出し（H2/H3）の書き方

### H2（大見出し）
- 読者がその見出しだけ読んでも内容がわかるレベル
- 例: 「AirPods Pro 2の音質は本当にいいのか？」

### H3（小見出し）
- 具体的なポイントを示す
- 例: 「低音がしっかりしていてポップスに最適」

## アフィリエイトリンクの入れ方

### 挿入タイミング
1. 商品紹介直後（最初の言及箇所）
2. 「おすすめ度が高い」と評価した直後
3. 記事末尾のまとめ/CTA

### プレースホルダー記法
```
[AFFILIATE: 商品名 | Amazon]
[AFFILIATE: 商品名 | 楽天]
```

### 文脈の作り方（自然な誘導）
- 悪い例: 「こちらから購入できます → リンク」
- 良い例: 「Amazonで価格をチェックしてみると → [AFFILIATE: ...]」
- 良い例: 「実際に私が購入した際は楽天がお得でした → [AFFILIATE: ...]」

## Note特有の注意事項

- **改行**: Noteはスマホ閲覧が多いので、2〜3行で段落を区切る
- **太字**: 重要ポイントは `**太字**` で強調（多用しない）
- **画像**: `[画像: 説明]` プレースホルダーで場所を示す（実際の画像は手動挿入）
- **ハッシュタグ**: 記事末尾に5〜8個（例: #ガジェット #イヤホン #レビュー）
- **アフィリエイト開示**: 必ず記事の最初か最後に開示文を入れる

## NGワード・表現

- 「最高」「最強」「絶対」など根拠のない最上級表現（単独使用）
- 「〇〇必見！」「衝撃の結果！」などのクリックベイト見出し
- 根拠のない「売れてます」「人気です」
- メーカー・ブランドの誹謗中傷
