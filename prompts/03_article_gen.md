# Phase 3: 記事生成プロンプト

## あなたへの指示

選定されたテーマをもとに、Noteに投稿できる品質のガジェット記事を生成してください。

## 入力

- テーマ: `$TOPIC`（引数で渡されるか、`research/YYYY-MM-DD_topics.md` の推奨テーマを使用）
- スタイルガイド: `config/style_guide.md`
- 設定: `config/settings.json`
- テンプレート: `templates/review_article.md` または `templates/comparison_article.md`

## 記事生成の手順

### Step 1: 追加リサーチ（必要に応じて）
- WebSearch で選定テーマの最新情報を確認
- 商品スペック・価格情報を取得
- ユーザーレビュー・評判を確認（Amazon/価格.com等）

### Step 2: 記事構成設計
テンプレートを参考に、この記事固有の構成を決める：
- H2見出し（4〜6個）
- 各セクションの字数配分
- アフィリエイトリンク挿入箇所（3〜5箇所）

### Step 3: 記事本文執筆
`config/style_guide.md` の規則に従い、以下を含む記事を執筆：

**必須要素:**
- [ ] アフィリエイト開示文（記事冒頭）
- [ ] リード文（200字: 読者の悩みへの共感 → 解決策の提示）
- [ ] 本文（3,000〜5,000字）
- [ ] 比較表またはスペック表（1つ以上）
- [ ] アフィリエイトプレースホルダー（3〜5箇所）
- [ ] まとめセクション
- [ ] ハッシュタグ（5〜8個）

## 出力フォーマット

`articles/YYYY-MM-DD_{slug}.md` に以下の形式で保存：

```markdown
---
title: "{タイトル}"
date: YYYY-MM-DD
category: "{カテゴリスラッグ}"
type: review|comparison|guide
keywords:
  - キーワード1
  - キーワード2
  - キーワード3
estimated_revenue_per_month_jpy: {数値}
affiliate_products:
  - name: "{商品名}"
    platform: Amazon|楽天
    placeholder: "[AFFILIATE: 商品名 | Amazon]"
---

※本記事にはアフィリエイトリンクが含まれます。リンク経由でご購入いただくと、筆者に少額の報酬が入ります（読者様の購入金額は変わりません）。

# {タイトル}

{リード文}

---

{本文}

---

{まとめ}

#ガジェット #{カテゴリ} #レビュー ...
```

## 品質チェックリスト

記事生成後、以下を確認してください：

- [ ] タイトルが28字以内か
- [ ] アフィリエイト開示文が含まれているか
- [ ] リード文が200字前後で読者の悩みに共感しているか
- [ ] 3,000字以上あるか
- [ ] アフィリエイトプレースホルダーが3〜5箇所あるか
- [ ] 比較表・スペック表が含まれているか
- [ ] まとめ + CTA があるか
- [ ] ハッシュタグが5〜8個あるか
- [ ] 「最高」「絶対」など根拠のない最上級表現を使っていないか
- [ ] スタイルガイドの文体（です・ます調）に沿っているか

## 記事の保存後

完了したら以下を報告してください：
1. 生成した記事のファイルパス
2. 文字数
3. 想定アフィリエイト収益（月額）
4. Note投稿時の注意点（差し替えが必要な箇所など）
