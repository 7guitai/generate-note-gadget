# Phase 3: 記事生成プロンプト

## あなたへの指示

選定されたテーマをもとに、Noteに投稿できる品質の学生向け商品紹介記事を生成してください。
**各商品を詳細に紹介・比較すること**がこのブログの最大の特長です。

## 入力

- テーマ: `$TOPIC`（引数で渡されるか、`research/YYYY-MM-DD_topics.md` の推奨テーマを使用）
- スタイルガイド: `config/style_guide.md`
- 設定: `config/settings.json`
- テンプレート: `templates/review_article.md` または `templates/comparison_article.md`

## 記事生成の手順

### Step 1: 最新情報リサーチ（**必須・スキップ不可**）

記事に登場するすべての商品について、以下を**必ずWebSearchで確認**してから執筆してください。

```
検索例:
  "{商品名} Amazon 2026 在庫 新品"
  "{カテゴリ} 学生 おすすめ 2026 ランキング"
  "{商品名} 価格 最安値 2026"
  "{商品名} レビュー 評判"
```

**確認必須項目:**
- [ ] Amazonで「新品」在庫があるか（中古のみの場合は代替品に差し替え）
- [ ] 現在の価格帯（¥〇〇〜）が実態に合っているか
- [ ] 後継モデルや新製品が出ていないか（古いモデルを推奨しない）
- [ ] マイベスト・価格.com等の最新ランキングと整合しているか

**在庫なし・廃番の場合:** その商品を記事から除外し、現在入手可能な代替品を選定すること。

### Step 2: 記事構成設計
テンプレートを参考に、この記事固有の構成を決める：
- H2見出し（4〜6個）
- 各セクションの字数配分
- アフィリエイトリンク挿入箇所（3〜5箇所）
- 各商品の詳細比較ポイント（スペック・使用感・コスパ）

### Step 3: 記事本文執筆
`config/style_guide.md` の規則に従い、以下を含む記事を執筆：

**必須要素:**
- [ ] アフィリエイト開示文（記事冒頭）
- [ ] リード文（200字: 学生の悩みへの共感 → 解決策の提示）
- [ ] 本文（3,000〜5,000字）
- [ ] 比較表またはスペック表（1つ以上）
- [ ] 各商品の詳細レビュー（スペックの意味を噛み砕いて説明）
- [ ] 学生の生活シーンに紐づけた使用感の解説
- [ ] アフィリエイトプレースホルダー（3〜5箇所）
- [ ] まとめセクション（明確な結論を提示）
- [ ] ハッシュタグ（5〜8個）

**詳細比較のルール（差別化の核）:**
- スペックは数値で示し、その数値が実際に何を意味するか解説する
- 「〇〇が良い」ではなく「〇〇が△△だから、□□な場面で役立つ」と具体的に書く
- 価格差に見合う性能差があるかを正直に評価する
- 学生の予算感（バイト代、仕送り）を意識した表現にする

## 出力フォーマット

`articles/YYYY-MM-DD_{slug}.md` に以下の形式で保存：

```markdown
---
title: "{タイトル}"
date: YYYY-MM-DD
category: "{カテゴリスラッグ}"
type: review|comparison
keywords:
  - キーワード1
  - キーワード2
  - キーワード3
estimated_revenue_per_month_jpy: {数値}
affiliate_products:
  - name: "{商品名}"
    platform: Amazon|楽天
    placeholder: "[AFFILIATE: 商品名 | Amazon]"
---

※本記事にはアフィリエイトリンクが含まれます。リンク経由でご購入いただくと、筆者に少額の報酬が入ります（読者様の購入金額は変わりません）。

# {タイトル}

{リード文}

---

{本文}

---

{まとめ}

#大学生 #{カテゴリ} #学生おすすめ #コスパ ...
```

## 品質チェックリスト

記事生成後、以下を確認してください：

- [ ] タイトルが28字以内か
- [ ] アフィリエイト開示文が含まれているか
- [ ] リード文が200字前後で学生の悩みに共感しているか
- [ ] 3,000字以上あるか
- [ ] 各商品のスペックが具体的な数値で記載されているか
- [ ] スペックの意味が学生にもわかるよう噛み砕いて解説されているか
- [ ] 学生の生活シーンに紐づけた説明があるか
- [ ] アフィリエイトプレースホルダーが3〜5箇所あるか
- [ ] 比較表・スペック表が含まれているか
- [ ] まとめに明確な結論（どれを買うべきか）があるか
- [ ] ハッシュタグが5〜8個あるか
- [ ] 「最高」「絶対」など根拠のない最上級表現を使っていないか
- [ ] スタイルガイドの文体（です・ます調）に沿っているか
- [ ] 学生の予算に配慮した表現になっているか

## 記事の保存後

完了したら以下を報告してください：
1. 生成した記事のファイルパス
2. 文字数
3. 想定アフィリエイト収益（月額）
4. Note投稿時の注意点（差し替えが必要な箇所など）
